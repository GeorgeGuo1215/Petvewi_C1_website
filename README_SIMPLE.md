# PetHealthAI Website

PetHealthAI 官方网站，用于展示宠物健康智能设备、PetMind AI 技术和团队信息。

## 快速开始

```bash
corepack enable
pnpm install
cp .env.example .env.local
pnpm dev
```

启动后访问 [http://localhost:3000](http://localhost:3000)。

## 常用命令

```bash
pnpm build  # 构建生产版本
pnpm check  # 检查代码
pnpm start  # 启动生产服务器
```

详细说明请查看 [README.md](README.md)。
